# Шпаргалка по Wireshark

Откройте файл PCAP. Начните с `Statistics → Conversations` (Статистика → Диалоги) и `Endpoints` (Конечные узлы), затем проверьте DNS, HTTP/TLS и отдельные потоки через `Follow TCP Stream` (Проследить поток TCP).

Фильтры отображения:

```text
dns
http.request
http.request.method == "POST"
tls.handshake.extensions_server_name
ip.addr == 192.0.2.10
tcp.stream eq 4
frame contains "keyword"
```

Фильтр отображения только скрывает или показывает пакеты; сам файл захвата он не меняет. Сверяйте абсолютное и относительное время, ответы DNS, повторные соединения, объём передачи, `User-Agent`, редкие домены и POST-запросы. Полезно выбрать пакет правой кнопкой и применить фильтр.

Содержимое TLS обычно зашифровано. `File → Export Objects` (Файл → Экспорт объектов) доступен для некоторых протоколов. Захват живой сети может требовать Npcap и прав администратора; уже выданный PCAP анализируется без подключения к сети.

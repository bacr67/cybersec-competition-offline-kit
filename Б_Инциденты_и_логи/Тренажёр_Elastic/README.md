# LogScope — учебный тренажёр Discover

Автономная учебная симуляция интерфейса Elastic Discover для тренировки расследования инцидентов. Это не настоящий Elastic/Kibana и не подключается к стенду соревнований.

## Запуск

1. Установи Node.js, если его ещё нет.
2. Открой PowerShell в этой папке.
3. Выполни `node server.js`.
4. Открой `http://127.0.0.1:8765` и обнови страницу.
5. Остановить сервер: `Ctrl+C`.

npm, интернет и сторонние библиотеки не нужны. Сервер доступен только на этом компьютере. События находятся в `events.json`, страница загружает их локально.

## Возможности и ограничения

- Учебные Data view: все события, Windows, Syslog, веб, Zeek, почта, артефакты.
- Поддерживаемый учебный поднабор KQL: `поле:значение`, `*`, `AND`, `OR`, `NOT`, скобки. Это не полная реализация KQL.
- `*` в отдельности означает «поле существует»; в шаблоне заменяет часть значения.
- Нажми строку события, чтобы посмотреть все поля.
- Ноль результатов означает только отсутствие совпадений в текущем наборе/фильтре. Это не доказывает отсутствие события.
- Анализируй время в UTC, сопоставляй `process.entity_id`, адреса, имена файлов и хеши между источниками.
- Стиль письма не доказывает, что его написал ИИ. Обосновывай признаки письма и отдельно отмечай неопределённость авторства.

## Как вести отчёт

Пиши параллельно с расследованием: краткое резюме; область и ограничения данных; временная линия с UTC; подтверждённые факты и источники; гипотезы/пробелы; затронутые учётные записи и узлы; оценка ущерба; сдерживание; восстановление; меры предотвращения. Для каждого вывода указывай конкретное событие/поле и уровень уверенности. Не утверждай причинную связь, если события лишь совпадают по времени.

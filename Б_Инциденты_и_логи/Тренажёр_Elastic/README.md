# LogScope — учебный тренажёр Discover

Автономная учебная симуляция в стиле Elastic Discover. Это не настоящий Elastic/Kibana и не подключение к системе соревнований.

Запуск в PowerShell из этой папки: node server.js
Открой http://127.0.0.1:8765. Остановить: Ctrl+C. Нужен Node.js; интернет и npm не нужны. Сервер слушает только этот компьютер.

Есть Data views Windows, Syslog, Web, Zeek, Почта и Артефакты; KQL-поднабор: поле: значение, *, AND, OR, NOT, скобки. Запросы можно сохранить в браузере.

Кейс покрывает Windows, SSH/Syslog, веб-сервер, Zeek, фишинговое письмо, статический результат разбора pickle/joblib. Все данные вымышленные; реального файла ВПО нет. Не загружай учебные pickle/joblib через pickle.load или joblib.load.

Маршрут: входы и PowerShell -> SSH/Python/cron -> веб 401/200 и модель -> письмо -> Zeek -> артефакт -> таймлайн, ущерб, сдерживание, восстановление, отчёт. Стиль письма не доказывает ИИ-генерацию.

# Шпаргалка по OWASP ZAP

1. Установить/открыть ZAP заранее; выбрать Manual Explore или Proxy.
2. Настроить браузер на proxy `127.0.0.1:8080`; сертификат ZAP импортировать только в тестовый браузер/профиль.
3. Добавить выданный хост в scope; просматривать History и менять отдельные параметры в Request Editor.
4. Начните с passive findings. Active scan выполняйте только если правила задания явно разрешают.
5. Находку подтвердить ручным request/response, экспортировать доказательство, записать endpoint/роль/влияние.

Контекстное меню сайта → Include in Context / Scope. Перед сдачей экспортируйте report или копируйте точные запрос/ответ. Add-on Marketplace без интернета может быть недоступен.

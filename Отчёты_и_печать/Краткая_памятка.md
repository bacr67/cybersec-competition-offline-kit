# Памятка на стол

**Сначала scope и сохранение доказательств.** Исходники не менять. Время и timezone записать. Каждый вывод сохранять с именем команды и источником.

**Пара:** один ищет, второй фиксирует доказательства и перепроверяет; каждые 20–30 минут синхронизация.

**A:** карта портов → endpoints/роли → авторизация/ввод/вывод → LLM prompt/context/tools → безопасный PoC → CVSS/отчёт.

**B:** источники → IOC → цепочка → UTC timeline → scope/ущерб → containment/recovery → краткий отчёт. ИИ-текст сам по себе не доказательство.

**C:** техника ATT&CK → источник/поля → запрос → TP и FP тесты → tuning → triage и dashboard. Нет телеметрии — нет надёжного детекта.

**D:** свойства → процессы → сеть → инъекции → файлы. Только VM организатора для динамического ВПО. Hash + timeline + подтверждение несколькими источниками.

**E:** формат → гипотеза → одна техника за раз → проверка результата; сначала лёгкие баллы.

**Отчёт:** факт / интерпретация / рекомендация / неизвестное разделять. У каждой находки указать источник и путь доказательства.

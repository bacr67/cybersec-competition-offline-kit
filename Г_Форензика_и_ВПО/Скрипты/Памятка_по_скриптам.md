# Скрипты модуля Г

```powershell
.\Г_Форензика_и_ВПО\Скрипты\Get-SampleStaticTriage.ps1 `
  -Path 'E:\case\evidence\suspicious_files' `
  -OutDir 'E:\case\work\sample_static'
```

Результаты: `Статические_метаданные.csv` и `Сводка_статического_триажа.md` с SHA-256/размером/временем/сигнатурой/первичными байтами и, если найден Sysinternals `strings.exe`, отдельные `*_strings.txt`. Скрипт образцы не запускает. Вывод строк и подпись — только первичные признаки; переходите к динамическому анализу исключительно в изолированной VM организатора.

Для инвентаризации образа/сегментов и создания манифест SHA-256:

```powershell
.\Г_Форензика_и_ВПО\Скрипты\Get-DiskImageManifest.ps1 `
  -Path 'E:\case\evidence\disk.E01' `
  -OutDir 'E:\case\work\disk_manifest'
```

Результат: `Манифест_образа.csv`. Если времени на хэширование большого образа нет, `-SkipHash` создаст CSV с именами, размерами и временными метками без SHA-256. Для папки с сегментами укажите саму папку; результат обязан быть вне неё. Быстрая шпаргалка по образам, Sleuth Kit, Registry Explorer и инструменты Eric Zimmerman: `..\Инструменты\Образы_дисков\Шпаргалка_по_образам_дисков.md`.

## Первичный отчёт по образу диска

Укажи первый сегмент образа (`.E01` или `.001`) и отдельную папку для результатов. Скрипт сам добавит следующие `.E02…` или `.002…`, если имена идут подряд:

```powershell
.\Г_Форензика_и_ВПО\Скрипты\Собрать_первичный_отчёт_по_образу.ps1 `
  -ImagePath 'E:\case\evidence\disk.E01' `
  -OutputDirectory 'E:\case\work\disk_triage' `
  -CaseName 'Дело 01'
```

В указанной папке появится новая подпапка разбора с уникальной датой/временем; внутри будут файлы:

- `Первичный_отчёт_по_образу.html` — открой двойным щелчком в браузере, это удобный вид отчёта; `Первичный_отчёт_по_образу.md` — тот же отчёт для редактирования;
- `Состав_образа.csv` — части образа, размер и SHA-256;
- `Кандидаты_на_проверку.csv` — строки и пути, совпавшие с эвристиками, с категорией и уверенностью;
- `Таблица_разделов.txt`, `ФС_раздел_*.txt`, `Список_файлов_*.txt` и `Сведения_об_образе.txt` — исходные выводы Sleuth Kit.

Для ускорения можно добавить `-SkipHash`; тогда контрольные суммы не будут рассчитаны. Самое долгое — хэширование больших частей и полный список файлов. Скрипт не читает содержимое всех файлов и не разбирает офлайн-кусты реестра; все совпадения вручную проверь в Autopsy/Registry Explorer.

### Другие форматы и параметры

В комплектной версии Sleuth Kit подтверждены типы `raw`, `ewf`, `vmdk`, `vhd`; по умолчанию работает автоопределение. `.E01` и `.001` можно передать одной первой частью. Для сегментов с другими именами, например `.aa/.ab`, укажи каждый файл в правильном порядке:

```powershell
$parts = @('E:\case\evidence\disk.aa', 'E:\case\evidence\disk.ab')
.\Г_Форензика_и_ВПО\Скрипты\Собрать_первичный_отчёт_по_образу.ps1 `
  -ImagePath $parts `
  -OutputDirectory 'E:\case\work\disk_triage' `
  -ImageType raw -SectorSize 512 -TimeZone 'EST5EDT'
```

Полезные параметры:

- `-ImageType Auto|raw|ewf|vmdk|vhd` — принудительно задать формат, если автоопределение ошиблось.
- `-SectorSize 512`, `1024`, `2048` или `4096` — размер сектора; выбирай по описанию образа/заданию. Неверный размер ломает разметку.
- `-Offset 2048` — начать анализ файловой системы с указанного сектора, если `mmls` не смог определить раздел. Значение именно в секторах, не байтах.
- `-TimeZone 'EST5EDT'` — часовой пояс исходного компьютера для отображения времени в `fls`; если он неизвестен, оставь пустым и не угадывай.
- `-MetadataOnly` — быстро получить только записи верхнего уровня, без рекурсивного обхода папок. Для полноценного поиска подозрительных путей режим не подходит.
- `-SkipHash` — пропустить SHA-256 и ускорить обработку больших сегментов.

Если вместо образа выдали папку с логически собранными данными, передай одну папку с `-ImageType logical`. Скрипт перечислит файлы через `fls`; таблицы разделов, свободного места и удалённых секторов в таком источнике нет. Файлы внутри логической папки скриптом не хэшируются; используй `Get-DiskImageManifest.ps1` или `Get-SampleStaticTriage.ps1`, если нужно отдельно хэшировать экспорт.

Ограничения: поддержка зависит от установленной версии Sleuth Kit. В этой сборке список можно увидеть так: `& '.\Г_Форензика_и_ВПО\Инструменты\Образы_дисков\SleuthKit\sleuthkit-4.14.0-win32\bin\mmls.exe' -i list`. VHDX, AFF/AFF4, QCOW/QCOW2, sparsebundle и зашифрованные образы этой сборкой не подтверждены; для них используй Autopsy либо официальный конвертер формата и работай только с копией. Скрипт не разбирает содержимое файлов, Registry hives, RAM и вредоносный код; отчёт — начальная инвентаризация, не вердикт.

## Первичный разбор дампа памяти Volatility 3

```powershell
.\Г_Форензика_и_ВПО\Скрипты\Собрать_первичный_отчёт_по_RAM.ps1 `
  -MemoryPath 'E:\case\evidence\memory.raw' `
  -OutputRoot 'E:\case\work\ram'
```

Скрипт использует Python 3 и локальные пакеты из `Инструменты\Volatility3-wheelhouse`; создаёт виртуальную среду `Среда_Volatility3` и запускает `windows.info`, `pslist`, `psscan`, `netscan`, `cmdline`, `malfind`, `dlllist`. По умолчанию Volatility получает параметр `--offline`, чтобы не пробовать скачивать символы. Если символов нет и интернет/скачивание разрешены правилами, повтори с `-AllowSymbolDownload`.

Если Python 3 не найден, в папке `Инструменты` лежит установщик `python-3.13.17-amd64.exe`. Запусти его вручную, затем повтори скрипт. Виртуальную среду он пишет в папку результатов, отдельно от исходного дампа. Если плагин вернул ошибку или пустой вывод, это не означает, что артефакт отсутствует: проверь формат памяти, символы и файл соответствующего плагина. Скрипт не ставит вердикт о компрометации.

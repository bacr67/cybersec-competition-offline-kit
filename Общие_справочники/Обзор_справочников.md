# Справочник по инструментам

Модульные папки содержат сами программы, архивы, правила и README-шпаргалки. Общие SHA-256 загруженных EXE/ZIP/Wheels находятся в `Контрольные_суммы_SHA256.txt`.

## Что есть локально

- A: Nmap 7.993 installer, OWASP ZAP 2.17.0 installer.
- B: Wireshark Portable 4.6.10, анализ PCAP офлайн.
- C: SigmaHQ rules snapshot.
- D: Autopsy 4.23.1 распакован; Ghidra 12.2 распакован + portable JDK 21; Python 3.13.17 installer; Volatility 3 версии 2.28.2 + dependency `pefile` в wheelhouse); Sysinternals Suite распакован.
- E: CyberChef 11.6.0 standalone HTML распакован.

Автоматические обновления, плагины и облачные фиды могут не работать офлайн. Установите/запустите крупные GUI заранее. Для живого capture могут потребоваться права и драйвер Npcap; для ПК без прав используйте PCAP, предоставленный организаторами.

## Не приложено

Nessus/OpenVAS и Elastic/Wazuh не включены: они требуют активации/плагинов либо инфраструктуры и, по заданию, SIEM должен быть развёрнут организаторами. Burp Suite installer не удалось загрузить через текущий инструмент доступа к файлам; базовый ручной proxy покрывает ZAP. Если нужен именно Burp, официальная ссылка: https://portswigger.net/burp/communitydownload. Пакет рассчитан примерно на 6.2 GiB; флешка 16 GB с запасом удобнее.

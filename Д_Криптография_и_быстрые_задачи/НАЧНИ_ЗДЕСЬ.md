## Дерево распознавания

- Hex: только `[0-9a-f]`, чётная длина. `bytes.fromhex(s)`.
- Base64: алфавит `A-Za-z0-9+/=`; `base64.b64decode(s)`.
- URL encoding: `%xx`, `+` может быть пробелом.
- XOR: повторяющиеся байты/ключ; ищите известный префикс/читабельность.
- Caesar/ROT: буквы сдвинуты; проверьте все 26 сдвигов.
- Hash: фиксированная длина не означает автоматически конкретный hash. MD5 32 hex, SHA1 40, SHA256 64, но подтвердите контекстом. Хэш не расшифровывается.
- Substitution/encoding: проверьте частоты, padding, magic bytes, printable ratio.
- AES/RSA: нужны параметры/ключ/nonce/IV; без них не угадывайте.

## Короткие примеры Python

```python
import base64
s='...'
print(bytes.fromhex(s))
print(base64.b64decode(s+'='*((-len(s))%4)))
print(bytes.fromhex(s).decode('utf-8','replace'))
# XOR одним байтом
b=bytes.fromhex(s)
for k in range(256):
    out=bytes(x^k for x in b)
    if sum(32<=x<127 or x in (9,10,13) for x in out)/max(1,len(out)) > .85:
        print(k,out)
```

## Хэши/пароли

Определи формат по контексту/соли/префиксу. `hashcat -m <mode> hash.txt wordlist.txt`; `john --wordlist=wordlist.txt hash.txt`. Только выданный hash/учебная задача. Ошибка mode обычно проявляется как parse error/no hashes loaded.
